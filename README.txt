camelyyy website (GitHub + Vercel)
- Put everything in this folder into a GitHub repo named camelyyy, then import it on vercel.com. No build step, no database needed.
- Keep version.json and the APK (camelyyy-x_y_z.apk) here; the apps read version.json to find updates.
- Windows installer: upload camelyyy-Setup.msi to a GitHub Release (latest).
